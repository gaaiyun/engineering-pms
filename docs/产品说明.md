# 产品说明

EngineeringPMS 用于工程结算团队的项目、任务、交接、卡点、通知和责任追溯。

## 核心对象

- 项目：经理、成员、计划周期、状态和自动进度。
- 任务：负责人、日期、优先级、前置任务、完成内容、下一步和卡点信息。
- 交接：任务完成时提交的下一步提案，经理审核后生成唯一的下游任务。
- 通知：任务分配、卡点、交接、审批和项目变化的站内实时消息。
- 审计：业务变更的只读责任记录。审核中心只对交接执行通过/驳回；普通审计记录只确认已阅。

## 主要流程

1. 经理创建项目、成员和任务。
2. 员工从工作台或“我的任务”进入任务详情。
3. 正常完成时必须填写交接标题、负责人和截止日期。
4. 遇到问题时填写卡点原因，可选择回退到同项目的前序任务。
5. 经理在审核中心通过或驳回交接；通过后系统只创建一个下游任务。
6. 项目详情汇总进度、任务、里程碑、成员、风险和活动记录。

上述关键步骤由服务端事务执行，任一步失败都会整体回滚。

## 跨端信息架构

| 设备 | 主导航 |
|---|---|
| 桌面键鼠 `>=1024px` | 完整侧栏 |
| 键鼠 `769-1023px` | 折叠侧栏 |
| 触控平板、手机、Capacitor App | 工作台、任务、项目、通知、我的 |

时间轴和看板是项目二级视图，不占主导航。AI 配置位于管理员系统管理中。

## 已知交付边界

- 当前 Android 产物默认是 Debug APK，不代表应用商店 Release 包。
- 小程序只保留无 DOM 的导航模型与 API 边界，尚无可发布小程序产物。
- 生产 PocketBase 升级不包含在本版本内。
- 原生后台提醒依赖 ROM、电池策略与通知权限，必须真机验证。

## 数据与安全

- employee 只能读取参与项目和相关任务，不能自行提权或直接改变状态机字段。
- manager 管理项目与流程，不能进入系统用户/Provider 配置。
- admin 管理账号、AI Provider 和数据导入。
- 停用账号不能密码登录或刷新旧会话。
- 项目使用归档代替永久删除；任务永久删除由服务端事务清理依赖。
- 实际员工账号、默认密码、LLM Key 和生产拓扑不写入公开仓库。
