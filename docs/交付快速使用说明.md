# EngineeringPMS 3.06 快速使用说明

## 登录

- Web：以私有交付清单中的生产地址为准
- 使用单独加密凭据包中的账号和初始密码登录。
- 首次登录必须设置新密码；新密码只由本人保管。
- 系统不开放自助注册，新员工账号由管理员创建。

## 项目负责人的日常流程

1. 在“项目”中新建项目，填写负责人、成员、起止时间和项目说明。
2. 进入项目详情后建立任务，指定负责人、优先级、期限和交付要求。
3. 在项目看板查看进度；使用卡片拖动手柄调整普通状态。
4. 任务完成、卡点或解阻时填写业务说明，系统同步生成通知和审计记录。
5. 在“审核中心”处理交接审批，在“通知”查看待办变化。
6. 在工作台或 MCP 日报中查看逾期、临期、卡点、待审批和人员负荷。

## 账号管理

- 管理员可在“系统管理 -> 用户管理”新增、编辑、停用或安全删除账号。
- 有项目、任务、评论或审计历史的账号应停用，不应永久删除。
- 管理员重置密码后，用户下次进入系统必须重新修改密码。
- 系统至少保留一个启用管理员，不能删除最后一个管理员。

## Agent / MCP

- MCP 入口：`<production-web-url>/mcp`。
- 华哥的 Agent 连接包含 24 个工具；除项目、任务、评论、交接和管理摘要外，另有受控的人员维护工具。人员维护仅能创建/修改/停用 employee、manager，不能创建或删除 admin，也不能修改 AI 配置或服务器。
- 归档、删除、批量改派和交接审批必须先查看 preview，再由人明确同意 confirm；不得让 Agent 自动连续执行。
- WorkBuddy 配置、项目负责人/老板提示词和 Skill 位于交付 ZIP 的 `Agent工具/华哥Agent接入/`，无需解密。该目录包含可用 MCP Key，只能私下发送；不要把包含员工初始密码的账号凭据包发给 Agent。

### 华哥重新配置人员

先让 Agent 列出全部人员（包括停用），再按“修改 → 停用 → 删除无引用账号 → 新建”的顺序执行。修改或重置密码后，临时密码只在当次响应出现一次，交给员工后立即要求改密。删除前必须先停用并执行预览；只要存在项目、任务、交接、评论、通知或审计引用，就只能停用或改名，不能硬删。每次写入后让 Agent 再查询一次核对结果，同一操作重试要复用原幂等键。
