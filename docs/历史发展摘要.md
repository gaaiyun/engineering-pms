# 历史发展摘要

本文件只保留有助于维护的版本脉络。原始对话、计划、调试 JSON 和截图已退出当前 Git 文件树；需要追溯时使用 Git commit/PR 和仓外受控归档。

## 2.x 基础期

项目建立了 PocketBase 数据模型、登录、项目、任务、经理工作台、通知和初版移动界面。早期实现使用页面自带导航、演示账号、浏览器 LLM Key 和前端多请求状态流转。

## 3.0–3.04 跨端期

引入桌面侧栏/TopBar、手机底栏、任务表格、看板拖拽、Android Capacitor 工程、Realtime 前台服务、交接/卡点/审计模型和多视口自动化测试。

这一阶段形成了大量原始计划和截图，但其中包含已失效路由、测试账号、个人绝对路径和实现中间态，不能继续作为当前文档。

## 2026-07 稳定化期

本轮先恢复本地开发记录、Git 提交和服务器事实，再完成：

- 导航唯一化与旧链接兼容；
- 项目详情和跨页面数据流；
- PocketBase 日志库修复与 systemd；
- 权限 reconciliation、账号停用和管理员保护；
- 服务端通知与通用 LLM 代理；
- 任务状态机、交接审批和删除事务化；
- 手机密度、正式头像、资料页、项目页、看板与时间轴优化；
- SDK/PocketBase 兼容版本固定；
- 仓库文档、旧截图和危险脚本清理。

## 维护原则

- 当前事实只写在 README、开发交接、验收矩阵、架构、数据库和部署手册。
- 版本历史写 Changelog 和 Git，不在多个长文重复。
- 测试结果必须带命令和时间，旧截图不代表当前验收。
- 生产主机、员工账号、密码、Key、会话路径和本地绝对路径属于私有部署信息。
- 不把开发工具名称、模型名称或自动化署名写入 commit message 或产品文档。
