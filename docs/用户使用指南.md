# 用户使用指南

## 登录与账号

使用管理员分配的用户名和密码登录。Web 默认保持登录；取消“保持登录”后，关闭浏览器会清除会话。App 会保持登录，直到主动退出。

首次取得默认密码后应立即在“我的 -> 系统设置 -> 修改密码”中更换。连续登录失败会触发短时锁定；账号被停用后，已有会话也不能继续刷新。

系统不开放自助注册。所有新账号均由管理员在“系统管理 -> 用户管理”中创建；管理员新增账号时需填写两次一致的初始密码，并可直接设置角色、部门、职位和启用状态。

## 工作台

工作台显示个人进行中、待办、逾期、卡点任务和未读通知。点击指标或列表行可进入对应任务或通知。

## 任务

- “我的任务”按进行中、待办、逾期和已完成分类。
- 逾期由截止日期实时计算，不依赖后台手工写入状态。
- 任务详情可查看负责人、日期、完成内容、下一步、评论和审计历史。
- 完成任务必须提交交接信息；系统不会提供绕过交接的批量完成。
- 卡点必须填写原因；若选择前序任务，系统会同步将前序任务恢复为进行中。
- 卡点解除后，前序任务、通知和审计会同时恢复。

## 项目

点击项目列表任意项目卡片进入项目总览。总览包含：

- 项目进度和任务统计；
- 当前任务、里程碑、成员与项目资料；
- 风险、卡点和最近活动；
- 项目看板与时间轴入口。

manager/admin 可按住任务卡右上角的拖动手柄跨泳道调整普通状态；点按卡片本身只打开详情，不会误触拖拽。拖到“卡点”或“已完成”会打开任务详情，要求填写完整业务信息。employee 只能点按查看，不显示拖动手柄。时间轴支持状态筛选、回到今天、缩放、负责人定位和任务直达。

项目不提供随手永久删除，完成后使用“归档项目”。

## 通知

通知按全部、未读、任务、交接、卡点和项目分类。前台收到 PocketBase Realtime 事件后会刷新列表；移动端支持滑动删除和标为已读。

通知链接会根据类型进入任务或项目。普通员工收到交接类通知时不会被带到无权限的审核中心。

## 审核中心

manager/admin 可访问：

- 普通审计日志用于搜索、筛选和确认已阅，不改变已经发生的业务状态。
- “交接审核”用于真正的通过或驳回。并发重复审批只允许第一次成功。

## 我的资料与设置

“我的资料”使用正式人员档案布局。默认头像用姓名末两个汉字作为大字标识，例如“陈志远”显示“志远”；可切换六种企业配色，也可上传真实照片。上传文件最大 5 MB。

设置页支持通知开关、修改密码、清除本地缓存和查看版本。清理缓存会保留当前登录凭证；退出账号才会清除凭证。

## 管理员

管理员在系统管理中可：

- 搜索、新增、编辑、停用和安全删除账号；
- 配置任意 OpenAI-compatible Provider 的名称、Base URL、默认模型和 API Key；
- 通过 JSON 批量导入用户、项目和任务。

账号已有项目、任务、评论或审计历史时只能停用，不能永久删除。管理员不能降低自己的角色，系统始终至少保留一个启用管理员。

## 常见问题

- 页面显示旧版本：在系统设置清理缓存并刷新。
- 登录后立即退出：检查账号是否停用，以及 PocketBase 是否可访问。
- 没有看到项目：确认自己已加入项目成员或任务负责人。
- 收不到实时通知：检查通知权限、App 电池策略、网络和 PocketBase `/api/realtime`。
- AI 不可用：由管理员检查服务端 Provider 配置；不要在浏览器中粘贴 API Key。
