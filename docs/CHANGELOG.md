## 3.04 release candidate — 2026-07

### 导航与 UI

- `AppShell` 成为唯一主导航，移除页面级重复侧栏和桌面底栏。
- 新增项目总览、系统用户/AI/导入路由和旧链接重定向。
- 手机统一更小字号、更高信息密度和更紧凑底部导航。
- 看板修复大屏首列不可达，完成/卡点拖动改为打开业务表单。
- 时间轴新增手机筛选、缩放、负责人定位和任务直达。
- 资料页改为正式人员档案，旧生成头像替换为稳定企业头像。

### 账号与权限

- PocketBase SDK 固定为与 Server 0.22.21 兼容的 0.21.5。
- 保持登录和会话存储修复；网络超时不再误清登录。
- 注册只能创建 employee；管理员新增/编辑/停用账号流程补齐。
- 停用账号不能密码登录或刷新旧 token。
- 防止管理员自降权、最后一个启用管理员被停用，以及删除有业务历史的人员。
- 收紧项目、任务、通知、交接、审计和设置集合规则。

### 服务端事务

- 完成任务 + 创建交接原子化。
- 卡点 + 前序回退原子化。
- 解阻 + 前序恢复原子化。
- 交接审批 + 唯一下游任务原子化并处理并发。
- 任务永久删除 + 依赖清理 + 项目进度重算原子化。
- 项目永久删除入口移除，改用归档。
- 普通审计只确认已阅，避免与真正交接审批冲突。

### AI

- 支持任意 OpenAI-compatible Provider、Base URL 和模型。
- API Key 仅存服务端，移除浏览器 Key 和直连 fallback。
- 代理增加角色、输入、模型、token、temperature 和错误脱敏限制。

### Android

- 新应用图标、启动图和 PWA 图标。
- Debug APK 构建要求显式传入后端 URL并检查产物。
- release 构建缺少私有 keystore 时主动失败。

### 运维与仓库

- 修复损坏 `logs.db` 并建立 systemd 守护模板。
- 增加生产权限、账号、项目成员与事务锁迁移。
- 原始调试截图、过期计划、演示数据库脚本和含默认账号的旧文档退出当前 Git 文件树。
- README、用户、架构、数据库、宝塔、APK 和开发交接文档统一为当前事实。
